System Requirements

  • CPU: 64-bit processor (x86_64), 2+ cores recommended
  • RAM: 4 GB minimum, 8 GB or more recommended for AI workloads
  • Disk Space: 20 GB minimum, 50 GB or more recommended
  • GPU: NVIDIA GPU recommended for AI workloads (but not required)
  • Display: 1024x768 or higher resolution

Installation Guide

Follow these simple steps to install NeuronOS on your computer.

1

Download the ISO

Download the latest NeuronOS ISO from the download section above.

2

Create a Bootable USB Drive

Use tools like Rufus (Windows), Etcher (all platforms), or dd (Linux) to create a bootable USB drive.

3

Boot from USB

Restart your computer and boot from the USB drive (you may need to change boot order in BIOS/UEFI).

4

Install NeuronOS

Follow the on-screen instructions to install NeuronOS. You can choose to install alongside your existing OS or replace it.

5

First Boot

After installation, restart your computer, remove the USB drive, and enjoy your new NeuronOS!
